# Background

Linktopath aims to be a link shortener anyone can host, through cloud providers
or on their own.

However, due to cloud provider limitations and differences in self-hosting
principles, I believe that Linktopath should provide multiple deployment
options.

The web-based frontend will be written in Preact for minimalism, and compiled to
plain JavaScript for compatibility, whereas the backend will be provided in the
following languages:

1. Python (WIP)
2. TypeScript (WIP)
3. Go (WIP)
4. Rust (WIP)
